

# 🟦 Square of Array Elements Using Pointer (C)

This C program finds the **square of each element** in a **1D array** using a **pointer**.

---
## 📖 How It Works

* User inputs the **size** and **elements** of the array ⌨️
* A **pointer** is assigned to the array
* Loop iterates through array using pointer arithmetic
* Each element is squared and printed 🔢

---

## 🧪 Sample Output

**Input:**

```
Enter the size of array: 4
Enter 4 elements:
2 3 4 5
```

**Output:**

```
Square of each element is:
4 9 16 25
```
