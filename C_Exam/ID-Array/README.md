

# 🔤 Vowel or Consonant Checker (C)

This C program checks whether a character entered by the user is a **vowel** or a **consonant** using a **`switch` statement**.

---



## 🧪 Sample Output

**Input:** `a`
**Output:** `a is a vowel.`

**Input:** `b`
**Output:** `b is consonant.`
