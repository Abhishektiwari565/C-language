

# 📊 Largest Element in 1D Array (C)

This C program finds the **largest element** in a **one-dimensional array** entered by the user.

## 🧪 Sample Output

**Input:**

```
Enter the size of array: 5
Enter 5 elements:
10 25 8 30 15
```

**Output:**

```
The largest element is: 30
```
