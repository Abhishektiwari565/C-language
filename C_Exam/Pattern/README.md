# 🔢 Square Number Pattern in C

This C program prints a **number pattern** using **nested `for` loops**, where each row contains the **square of the row number** repeated.

---

## 📖 How It Works

* Outer loop controls the **rows**
* Inner loop controls the **columns**
* Each row prints the **square of the row number**
* The number is repeated according to the row count 🔁

---

## 🧾 Output Pattern

```
1
4 4
9 9 9
16 16 16 16
25 25 25 25 25
```
