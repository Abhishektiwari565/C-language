
# 🔁 Reverse a String in C (Without Library Functions)

This C program reverses a **string** using a **user-defined function**, without using any string library functions.

---


## 📖 How It Works

* Takes a string as input ⌨️
* Finds the **length of the string manually**
* Swaps characters from **start and end**
* Continues until the string is reversed 🔄

---

## 🧪 Sample Output

**Input:**

```
hello
```

**Output:**

```
Reversed string: olleh
```
